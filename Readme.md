# DPI Engine

A Python-based Deep Packet Inspection (DPI) engine
for parsing network packet captures and extracting
network/application-level information.

## Features
- PCAP file parsing
- IPv4 TCP/UDP packet processing
- Packet metadata extraction
- SNI / domain extraction
- Domain identification from TLS traffic
- Modular milestone-based development

## Tech Stack
- Python
- Scapy
- PCAP
- TCP/IP
- UDP
- TLS/SNI
- Git & GitHub

## Project Structure

milestone-1/
  Basic packet parsing

milestone-2/
  SNI and domain extraction

## How to Run

python3 main.py test_dpi.pcap
